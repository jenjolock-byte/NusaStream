# NusaStream — Android TV starter

Starter Android app with a TV-friendly dark UI and Media3 playback dependencies.

**Status:** This is a starter UI only. It does not yet include streaming catalogs/add-ons, a configured real video source, or a Cloudflare WARP tunnel. Demo cards are placeholders.

## Build APK
Open Actions → Build NusaStream APK → Run workflow. Download the `NusaStream-debug-APK` artifact after a successful run.
